# 一级标题

段落之间用空行分隔。

第二个段落。_斜体_、**粗体**，以及 `等宽字体`。无序列表
长这样：

- 这个
- 那个
- 另一个

注意 --- 不考虑星号的话 --- 实际正文内容
从第 4 列开始。

> 引用块是
> 这样写的。
>
> 如果需要，它们可以
> 跨多个段落。

用 3 个连字符表示破折号。用 2 个连字符表示范围（例如 "it's all
in chapters 12--14"）。三个点 ... 会转换成省略号。
支持 Unicode。☺

## 二级标题

这是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

再次注意正文是从第 4 列（左侧第 4 个字符）开始的。下面是一个代码示例：

    # Let me re-iterate ...
    for i in 1 .. 10 { do-something(i) }

你可能已经猜到，那就是缩进 4 个空格。顺便说一句，如果你喜欢，
也可以不用缩进，而用围栏代码块：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

（这样复制粘贴更方便）。你还可以给围栏代码块标记语言，
让 Pandoc 对它做语法高亮：

```python
import time
# Quick, count to ten!
for i in range(10):
    # (but not *too* quick)
    time.sleep(0.5)
    print i
```

### 三级标题

现在是一个嵌套列表：

1. 首先准备这些食材：

    - 胡萝卜
    - 芹菜
    - 小扁豆

2. 烧一些水。

3. 把所有东西倒进锅里，然后按
   以下算法操作：

        find wooden spoon
        uncover pot
        stir
        cover pot
        balance wooden spoon precariously on pot handle
        wait 10 minutes
        goto first step (or shut off burner when done)

    别碰木勺，否则它会掉。

再次注意文字总是对齐在 4 空格缩进处（包括
上面第 3 项续写的那一行）。

文档](local-doc.html)的链接，以及指向本文档中
